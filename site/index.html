One verdict per agent.

allowedThe agent got the same page as the browser.
blockedAn error status (403, 401, 404, 5xx) instead of the page.
challengedA WAF or CAPTCHA challenge page.
rate-limitedA 429, with the Retry-After delay.
cloakedThe visible text differs substantially from what the browser got.
robots-disallowedrobots.txt tells this agent to stay out.
errorThe request failed: DNS, TLS, timeout or connection reset.

Commands

acurl <url>Fetch a URL as every agent, classify each response and score the page.
acurl robots <url>robots.txt verdict per agent, Content Signals, sitemaps and llms.txt.
acurl batch [file]Check URL lists, CSV files, stdin or whole sitemaps.
acurl watch <url>...Re-check on a schedule and alert on changes.
acurl report <file>Render a saved JSON report as HTML, Markdown, SARIF, JUnit or CSV.
acurl serveLocal web UI and JSON API.
acurl mcpMCP server for AI assistants.
acurl tapWatch the API traffic of Claude Code, Codex, Gemini CLI or Grok, like tcpdump.
acurl profiles list | showBrowse the agent profile catalog.
acurl keygenCreate an Ed25519 key for Web Bot Auth signing.
acurl initWrite a commented .acurl.yaml config file.
acurl completionShell completions for bash, zsh, fish and PowerShell.
